## B. PRODUCT MODEL (entities actually present)

All entities from backend/app/models/domain.py + db.py tables [FACT]:
1. **Target** — user-registered website. Fields: id(uuid), name, url, domain, status(9-state enum), health float, monitoring_enabled, schedule(MANUAL/5M/15M/HOURLY/DAILY), last_run, last_healed, is_demo, configuration JSON. Lifecycle: READY→INSPECTING→RUNNING→HEALTHY/DEGRADED/FAILED→HEALING→DISABLED. Created by POST /api/targets or DB seed (`default_target` = Exploit-DB proxy, is_demo=1, db.py:73–79). Frontend: current wizard NEVER displays it [FACT].
2. **TargetInspection** — per-target DOM recon: page_type(TABLE/CARD_GRID/ARTICLE_LIST/SINGLE_DOCUMENT/UNKNOWN), candidate_fields/selectors/containers, sample_records, warnings. Created by POST /api/targets/{id}/inspect (Playwright render → BS4 structural analysis, target_inspector.py).
3. **ExtractionSchema** — typed fields (name/type/description/required/selector_hint/normalization/validation_rule) + version + intent_prompt. Generated by Gemini from natural-language intent (schema_generator.py), human-editable via PUT.
4. **ScraperDefinition** — binds target+schema to Bright Data collector_id. Default collector `c_sentinel_cve_threats` hardcoded ×7 sites.
5. **ScraperRun / ScraperJobState** — run lifecycle IDLE→RUNNING→BROKEN→EVIDENCE_COLLECTING→HEALING→AWAITING_APPROVAL→APPROVING→HEALTHY/FAILED.
6. **DynamicRecord** — extracted rows {target_id, run_id, data JSON, is_simulated}. The real product data.
7. **ThreatRecord** — LEGACY CVE-shaped record (cve_id UNIQUE, severity, published_date…), auto-derived when dynamic row has cve-like key (recovery_orchestrator.py:293–304). What the frontend actually displays.
8. **TelemetryEvent** — DAG node_id+status+message+payload; persisted + SSE broadcast.
9. **RepairProposal** — AI output schema: diagnosis, target_field, evidence, proposed_selector, repair_prompt, confidence, expected_output, source_type(AI_GENERATED|HEURISTIC_FALLBACK), model_used.
10. **ChaosMode** — CLEAN/CLASS_RENAMED/TABLE_TO_CARDS/DEEP_NESTING/CONTAINER_WRAP (server-side mutation of demo proxy HTML).

Missing entities a full product would have: users/orgs/auth/tenants/billing/notifications/schedules-executor [FACT — absent].
